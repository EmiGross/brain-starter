# Context/

The "who is the owner" layer. Stable knowledge that changes slowly. Loaded selectively per task.

## Files

- `me.md` — identity, working style, how they make decisions
- `work.md` — what they do professionally: services, pricing, how it runs
- `clients.md` — who they work for/with, typical projects, how those people think
- `voice.md` — how the owner sounds in writing; raw writing samples; visual style
- `strategy.md` — this year's priorities and explicit nos
- `tools.md` — hardware/software stack they work with
- `personal.md` — life outside work: routines, interests, what the brain should know

The onboarding interview creates these; the exact file set adapts to the owner's profession (e.g. `gear.md` instead of `tools.md` for a filmmaker, no `clients.md` for an employee).

## Rules

- Update these files when durable facts change, not for daily events (those go to `Daily/`).
- When updating, preserve replaced wording in a `## History` section at the bottom.
- Only create a file when there is real content for it.
