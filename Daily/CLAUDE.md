# Daily/

One note per working day: `YYYY-MM-DD.md`. The short-term memory of the vault.

## Note shape

```markdown
---
type: daily
date: YYYY-MM-DD
---
## Heute passiert
## Entscheidungen
## Tasks
- [ ] offene Aufgabe
## Morgen
```

## Rules

- Session summaries and meaningful work get appended here.
- Roll incomplete tasks forward to the next day's note.
- Durable knowledge (a decision, a lesson, a client fact) gets promoted to `Context/` or `Intelligence/` — the daily note keeps only the log line.
