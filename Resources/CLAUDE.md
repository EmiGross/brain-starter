# Resources/

Reusable assets: templates, prompts, checklists, frameworks, swipe files.

## Examples of what lives here

- Angebots- und Rechnungs-Templates
- Briefing- und Projekt-Templates
- Checklisten für wiederkehrende Abläufe
- Prompt-Bausteine, die sich bewährt haben

## Already here

- `claude-code-mods.md` — the five Claude Code mods that ship with this vault, how to install and remove them
- `scripts/claude-code-mods/` — their source code (one folder per mod)
- `scripts/doc2md` — converts PDF, docx, xlsx and pptx to Markdown (root `CLAUDE.md` rule 10)

## Rules

- One file per asset, descriptive kebab-case filename.
- If something from `Daily/` or a project turns out to be reusable, promote a copy here.
