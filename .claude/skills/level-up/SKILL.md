# Level-Up — One Improvement Per Week

Short interview, then one concrete proposal. German, conversational.

## Procedure

1. Read the last `audit-*.md` report (if any), the last 7 `Daily/` notes, and `connections.md`.
2. Ask the owner max 3 questions, one at a time:
   - "Was hat dich diese Woche am meisten Zeit gekostet, das sich wiederholt hat?"
   - "Wo musstest du mir diese Woche Kontext erklären, den ich hätte wissen müssen?"
   - One follow-up based on their answers.
3. Propose exactly **one** improvement. Pick the highest time-saved-per-effort ratio. It can be: a new skill, a new Context file, a new connection, a template in `Resources/`, or a recurring routine.
4. If the owner says yes: build it now, in this session, end to end.
5. Log the decision to `Intelligence/decisions/entscheidungs-log.md`.

## Rules

- One proposal, not a list. If the owner rejects it, offer the runner-up.
- The proposal must reference concrete evidence ("du hast 3x diese Woche X gemacht"), not generic best practice.
